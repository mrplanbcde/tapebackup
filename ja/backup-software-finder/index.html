テープバックアップソフトウェア：最適なLTO向け製品の選定

最適なテープバックアップソフトウェアはテープの活用方法によって異なります。仮想環境中心で二次コピーとしてテープを使う場合はVeeam、大規模混在環境にはCommvault、低予算にはNakivo、シンプルなアーカイブには無料のLTFSが適しています。

ハードウェアの準備は全体の半分にすぎません。環境、テープの用途、データ規模、予算に関する四つの質問に答えるだけで、お使いのLTOドライブやライブラリに適したバックアップソフトウェアの候補が絞り込まれます。

テープバックアップソフトウェアを選ぶ前の確認事項

候補となる製品を選定する際は、お手持ちのドライブやライブラリに対してこれら六つの点を確認してください。ハードウェア面についてはライブラリガイドおよびバックアップ計算ツールが役立ちます。

確認事項確認が重要な理由
LTOの世代とインターフェースソフトウェアがお使いのLTO世代およびドライブやライブラリの接続規格（SASまたはFibre Channel）をサポートしていることを確認してください。サポートされていないドライブは購入の妨げになる可能性があります。
LTFSLTFSを書き込めるソフトウェアを使用すると、将来ソフトウェアがなくてもテープを読み取り可能な状態に保てるため、ベンダーの変更や数年後のリストア時に役立ちます。
ストリーミング速度LTOドライブには安定したデータ供給が必要です。ドライブが停止と再開を繰り返さないよう、ソフトウェアがジョブをどのようにステージングまたは多重化するかを確認してください。
暗号化とWORMLTO-4以降のドライブはAES-256で暗号化し、WORMカートリッジは上書きを防止します。ソフトウェアが鍵とWORMメディアをどのように管理するか確認してください。
カタログとリストア多数のカートリッジにまたがる検索や単一ファイルの迅速なリストアはカタログ機能に依存します。本格運用に入る前に完全復元テストを実施してください。
オフサイト保管と保持期間建物の外に出るテープのメディア追跡、有効期限とリサイクルのルール、すべてのカートリッジの所在記録に対応しているか確認してください。

LTOテープへのバックアップに最適なソフトウェアは何ですか？

お使いの環境によって異なります。仮想環境が中心でテープを二次コピーとして保持する場合はVeeamが一般的な選択肢であり、物理・仮想・クラウドの大規模混在環境にはCommvaultが適しており、小規模環境にはNakivoがより低コストな選択肢となります。上記のファインダーを使えば、四つの質問で絞り込むことができます。

LTOテープへの書き込みにバックアップソフトウェアは必要ですか？

単純なアーカイブであれば不要です。LTFSを使用すると、ドライブベンダーの無料ツールを利用して、ドライブのようにLTO-5以降のカートリッジにファイルをコピーできます。バックアップソフトウェアは、LTFSに欠けている機能、すなわちスケジュール設定、多数のカートリッジにまたがる検索可能なカタログ、検証、保持ルール、ライブラリ制御を追加します。

Veeamはテープへのバックアップに対応していますか？

はい。Veeam Backup & Replicationはテープライブラリやスタンドアロンドライブへバックアップを書き込むことができ、通常はディスク上のバックアップの二次コピーまたは長期保管用コピーとして利用されます。購入前にお使いのドライブやライブラリの世代がベンダーの対応一覧に含まれているか確認してください。

Microsoft 365をテープにバックアップできますか？

直接はできません。Veeam for Microsoft 365などのツールでSaaSデータをバックアップし、オフライン保管や長期保持が必要な場合にそのリポジトリをテープにコピーします。

テープバックアップソフトウェアを選ぶ前に何を確認すべきですか？

ご使用のLTO世代とドライブまたはライブラリのインターフェース（SASまたはFibre Channel）に対応しているか、LTFS書き込みが可能か、暗号化、WORM、オフサイトメディア追跡の処理方法、カタログからのリストアの速度と信頼性を確認してください。導入前に完全リストアのテストを行ってください。

無料のテープバックアップソフトウェアはありますか？

はい。Bacula Community、Bareos、Amandaはテープドライブとライブラリをサポートするオープンソースのバックアップシステムであり、シンプルな用途にはtarとLTFSも利用できます。ライセンス料は不要ですが、カタログ、スケジュール設定、監視はご自身で構築・保守する必要があります。
