LTOテープとオブジェクトストレージ

オブジェクトストレージはミリ秒で応答しますが毎月課金されます。LTOテープはライブラリからで分単位ですが、LTO-9で100 TBの二コピーなら費用は一度だけ$ 8,808から$ 14,839で、オフラインのカートリッジはランサムウェアの手が届きません。そのため、大規模なアーカイブの多くは両方を使っています。

短い答え

LTOテープとオブジェクトストレージのどちらを選ぶ？

オブジェクトストレージ（Amazon S3と、同じAPIを使うクラウドや自社サーバー上のサービス）は、すべてのオブジェクトをAPIの背後でオンラインに保つため、どのアプリケーションもミリ秒で読めます。LTOテープはほとんどがオフラインのカートリッジにデータを保存するため、ライブラリでも読み出しに分単位かかりますが、何年も保存する場合のTBあたりの費用は標準のオブジェクトストレージのごく一部で、棚にあるカートリッジはネットワーク攻撃の手が届きません。

大量のデータを持つ組織の多くは両方を使っています。頻繁に読むデータはオブジェクトストレージに、アーカイブとオフラインコピーはテープに置きます。テープ自体をS3インターフェースで見せる製品もいくつか出ており、これについては下で説明します。

両方を同時に

テープの上にS3

S3-to-tapeゲートウェイは、S3またはS3 Glacier APIでオブジェクトを受け取り、ライブラリ内のLTOカートリッジに書き込みます。多くの場合、新しいオブジェクトはディスクに保持します。S3をすでに使えるアプリケーションは、テープ専用のソフトウェアなしでテープにアーカイブできます。当サイトの Ledger で評価した例には、Spectra BlackPearl、Grau Data XtreemStore、PoINT Archival Gateway、S3ゲートウェイ付きの Versity ScoutAM、QStar があります。ご自身のデータ量とチームに合わせて比べるには、テープアーカイブ・アドバイザーをお試しください。

判断

どちらを選ぶべきか

  • オブジェクトストレージを選ぶ場合：アプリケーションが頻繁にデータを読む場合、どこからでもアクセスしたい場合、データセットが小さい場合です（およそ15 TB未満では、ドライブの方が何年分ものクラウドストレージより高くなります）。
  • LTOテープを選ぶ場合：数十テラバイト以上ずつ増えるアーカイブ、何年も保存が必要なデータ、3-2-1計画のオフラインコピーです。
  • 両方を使う場合：アーカイブにS3アプリケーションからアクセスできる必要があり、しかも安く保存したいときです。ライブラリの前にS3-to-tapeゲートウェイを置くか、頻繁に使うデータをオブジェクトストレージに置き、残りをテープに階層化します。

LTOストレージの仕組みと現在のTBあたり費用は、LTOストレージ解説にあります。

LTOテープはオブジェクトストレージより安いですか？

S3 Standard や Wasabi のような標準のオブジェクトストレージと比べれば、はい、大幅に安くなります。LTO-9で100 TBの二コピーなら、ドライブ込みで一度だけ$ 8,808から$ 14,839です。クラウドのアーカイブ階層と比べると、容量とリストア次第です。Glacier Deep Archive に100 TBを五年間置くとストレージ費用は$ 5,532で、テープより安くなりますが、一度全部を読み戻すと約$ 8,615が加わります。およそ500 TBを超える場合や、定期的にリストアする場合は、テープの方が安くなります。

LTOテープはオブジェクトストレージより速いですか？

大きなファイルのストリーミングでは、LTO-9ドライブは非圧縮で最大400 MB/s で書き込みます。ランダムなファイルの最初のバイトは、オブジェクトストレージの方がはるかに速く、ミリ秒に対して、ライブラリ内のテープでは一、二分ほどです。

S3をテープで使えますか？

はい。Spectra BlackPearl、Grau Data XtreemStore、PoINT Archival Gateway などのS3-to-tapeゲートウェイは、S3またはS3 Glacier のリクエストを受け取り、オブジェクトをLTOカートリッジに保存します。

オブジェクトストレージはランサムウェアに対して安全ですか？

Object Lock またはイミュータビリティを有効にし、アクセスキーを厳格に管理すれば、安全にできます。テープは物理的なエアギャップを加えます。棚にあるカートリッジには、ネットワーク経由では一切届きません。

テープをオブジェクトストレージに置き換えるべきですか？

完全に置き換えられるとは限りません。多くのサイトは、頻繁に使うデータをオブジェクトストレージに置き、アーカイブとオフラインコピーにテープを使っています。データを長く保存するほど、テープのTBあたりの費用が下がるからです。
