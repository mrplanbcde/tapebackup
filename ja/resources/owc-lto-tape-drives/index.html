ドライブガイド

OWC Mercury Pro と Archive Pro LTOドライブ

OWCは、Thunderbolt 接続のLTOドライブ（旧 Mercury Pro LTO）を Archive Pro として販売しています。LTO-7、LTO-8、LTO-9の各バージョンがあり、IBMドライブを内蔵し、Hedge Canister が付属します。OWCの米国ストアでの価格は$ 5,999.99のLTO-7から$ 12,499.99のLTO-9までです。Archive Pro Ethernet は10 GbE でドライブを共有します。OWCのLTO-10ドライブはまだありません。

ラインナップ

OWCの現行LTOドライブ

OWC (Other World Computing) は、デスクトップ型エンクロージャーに入ったLTOテープドライブを販売しており、主な対象はMacユーザーと映像チームです。現在の製品ラインは二つあります。

  • OWC Archive Proは、LTO-7、LTO-8、LTO-9ドライブを搭載したデスクトップ型で、Thunderbolt で接続します。データの一時置き場として、4または8 TBの内蔵SSDをオプションで選べます。
  • OWC Archive Pro Ethernetは、同じ考え方をネットワーク機器にしたもので、10ギガビットEthernet (iSCSI) でドライブを共有します。2025年四月に発売されました。

Mercury Pro LTOは、Thunderbolt ドライブの以前の名称です。OWCの現行マニュアルのタイトルは「Archive Pro LTO | Mercury Pro LTO」で、Mercury Pro の所有者をレガシーユーザーと呼んでいます。そのため、検索される Mercury Pro LTO-9 とLTO-7のモデルは、実際には現在 Archive Pro として販売されています。2026年十月17日時点で、OWCのLTO-10製品は見つかりませんでした。

LTOのルールは、エンクロージャーが何であっても同じです。LTO-9ドライブはLTO-8とLTO-9のカートリッジを読み書きでき、それより古いものは扱えません。アーカイブがLTO-6やLTO-7にある場合は、選ぶ前に、どのモデルがそれを読めるか確認してください。LTO-7はすでに三世代前なので、LTO-7のキットは主に、既存のLTO-7アーカイブを読む、または拡張する用途で意味があります。

2026年十月17日時点で、現行の Archive Pro や Archive Pro Ethernet の独立したレビューは見つかりませんでした。これらのドライブは当サイトでは検証していません。

向いている人

OWCのドライブが適している場合

向いている用途：Thunderbolt で差し込むだけの一台がほしい、Macを使う映像・写真スタジオで、アーカイブソフト付きで、コンピューターの中に何も入れる必要がない場合です。Archive Pro Ethernet は、複数の編集者で一台のドライブを共有したい小規模チームに向いています。

ほかを探すべき場合：SASポートのあるサーバーをすでにお持ちなら、HPE、IBM、Quantum のSAS外付けドライブ単体の方が安く済みます。LTO-10が必要な場合、OWCはまだ提供していません。多数のカートリッジ用のライブラリが必要ならLTOテープライブラリをご覧ください。ほかのデスクトップ型 Thunderbolt ブランドはLTOドライブ購入ガイドで、YoYotta や Archiware P5 などほかのアーカイブソフトはテープアーカイブ・アドバイザーで扱っています。

OWC Mercury Pro LTO は今も販売されていますか？

名称が変わりました。OWCは現在、Thunderbolt 接続のLTOドライブを Archive Pro として販売しており、マニュアルは Archive Pro と Mercury Pro LTO の両方を扱っています。LTO-7、LTO-8、LTO-9のバージョンが掲載されています。

OWC Archive Pro にはどのドライブが入っていますか？

IBM LTO Ultrium ドライブです。LTO-9モデルは IBM Ultrium 9 のメカニズムを使います。最初の2020 Mercury Pro LTO は IBM LTO-8 ドライブを使っていました。

OWC Archive Pro LTO-9はいくらですか？

2026年十月17日時点のOWC米国ストアで、Hedge Canister 付きキットは$ 12,499.99、8 TBの内蔵SSD付きなら最大$ 14,899.99です。Archive Pro Ethernet LTO-9は$ 14,999.99で掲載されています。

OWC Archive Pro は Windows で使えますか？

はい。OWCは、macOS と Linux のほか、Windows 10と11、Windows Server 2022に対応と記載しています。接続は Thunderbolt なので、PCには Thunderbolt ポートが必要です。

OWCはLTO-10ドライブを作っていますか？

2026年十月17日時点では販売していません。Archive Pro と Archive Pro Ethernet は、LTO-7、LTO-8、LTO-9のドライブ付きで販売されています。

Archive Pro と Archive Pro Ethernet の違いは何ですか？

Archive Pro は Thunderbolt でコンピューター一台に接続します。Archive Pro Ethernet はネットワーク上に置かれ、10ギガビットiSCSIで複数のワークステーションとドライブを共有します。
