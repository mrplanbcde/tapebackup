保管ガイド

LTOテープの保管方法

LTOテープの長期保管は、16から25 °C（61から77 °F）、相対湿度20から50%で、ケースに入れて縦に置き、磁石と日光から離します。使う前にドライブのある部屋で24時間なじませ、二つ目のコピーは別の拠点に置いてください。

条件

LTOテープの温度と湿度

用途温度相対湿度注記
長期（アーカイブ）保管16から25 °C（61から77 °F）20から50%IBMの推奨保管範囲。Fujifilmは長期
短期保管16から32 °C（61から90 °F）20から80%IBMの許容保管範囲。Fujifilmは短期なら35 °Cまで許容
ドライブ内（推奨）15から25 °C（59から77 °F）20から50%Fujifilm LTO-9の推奨動作範囲
ドライブ内（許容）10から45 °C（50から113 °F）10から80%IBMの動作範囲
輸送−23から49 °C（−9から120 °F）5から80%IBMの値。テープ自体は52 °Cを超えてはいけません（Fujifilm）

数値の出典はIBM LTO Ultrium データカートリッジのデータシート（LTO-9とLTO-10）とFujifilm LTO-9のデータシートです。Overland-Tandberg のテープ取り扱いガイドも同じアーカイブ範囲を示しています。すべての範囲は結露がないことが前提で、IBMは最高湿球温度を26 °Cと定めています。

  • 安定させる。ゆるやかで小さな変化は問題ありませんが、一日の中での大きな変動や結露は害になります。空調のあるオフィスの閉じたキャビネットは、ガレージや外壁際よりも適しています。
  • 使用前に慣らす。IBM、Dell、Overland-Tandberg はいずれも、使用前にドライブと同じ部屋に24時間置くよう求めており、結露を避けるために必要ならそれ以上置きます（IBM、Dell）。
  • 磁石、熱、日光から離す。IBMは、カートリッジを100エルステッドを超える漏れ磁場にさらさないよう述べています。Overland-Tandbergは、大電流のケーブル、電源装置、モーターから8から12 cm（3から5インチ）離すよう勧めています。直射日光を避け、暖房器具の近くには置かないでください。

これらの条件は、30年のアーカイブ定格の前提です。テープの保存期間について詳しくはLTOテープの寿命をご覧ください。

テープには紙用の耐火金庫では足りません。紙が燃え出す温度より低く保つ設計で、その温度はテープが耐えられる温度よりはるかに高いからです。磁気メディア向けの定格のキャビネットか金庫（米国では磁気テープとフィルムの定格が UL 72 Class 150、紙は Class 350）を探すか、別の拠点に置いた二つ目のコピーに頼ってください。バーコードラベルとクリーニングカートリッジについては、クリーニングテープ、ラベル、ケースで説明しています。

オフサイト

オフサイト保管とローテーション

データのコピーの一つは、本拠点の火災、洪水、侵入が及ばない場所に常に置いておくべきです。テープの場合、それはカートリッジを予定に沿って建物の外へ持ち出すことを意味します。

  • 日次、週次、月次のセット。一般的な方式（祖父・父・子と呼ばれます）では、日次のテープを一、二週間、週次のテープを一、二か月、月次のテープを一年以上保持し、最新の週次または月次のセットをオフサイトに置きます。
  • アーカイブコピー。一度書いたら終わりのアーカイブは、コピーを二つ作り、最初から一つを別の拠点に置きます。
  • 記録簿。どのカートリッジがどこにあり、誰がいつ動かしたかを記録します。バックアップソフトやライブラリは、これを「ボールティング」として管理できます。
  • 持ち出すものは暗号化する。車や配送車の中のカートリッジは紛失することがあります。ドライブの暗号化（AES-256、LTO-4以降）を使えば、テープをなくしても何も漏れません。

保管業者を使う場合は、テープをどこでどう保管するか（温度と湿度の管理）、カートリッジをどれだけ早く返却できるか、管理の連鎖をどう記録するか、拠点間でカートリッジをどう輸送するかを確認してください。オフサイトのテープが今も重要な理由は、オフサイトテープバックアップは多くの「十分な」計画に勝るで論じています。

取り扱い

取り扱いチェックリスト

  • カートリッジはシェルを持ち、テープに触れたりリーダーピンを引いたりしないでください。
  • 落とさないでください。落としたカートリッジは、唯一のコピーを保存する前にテストするか、使用をやめてください。
  • ドライブやライブラリから出しているときは、必ずケースに入れておきます。
  • ラベルは、ドライブ内ではがれる可能性のある手書きのシールではなく、正規のバーコードラベルを使います。
  • 縦に置き、決して平らに積み重ねないでください。車内に放置するのも厳禁です。
  • 一、二年ごとにカートリッジの一部を読み戻し、アーカイブが今も読めることを確認します。

LTOテープは何度で保管すべきですか？

IBMとFujifilmによると、長期保管は16から25 °C（61から77 °F）です。短期間ならIBMは16から32 °Cを許容しますが、テープ自体は52 °Cを決して超えてはいけません。

LTOテープの保管に最適な湿度は？

長期保管は相対湿度20から50%で、結露がないことが条件です。短期保管なら80%まで許容されますが、30年の定格は安定した乾燥環境を前提にしています。

LTOテープは平置きと縦置きのどちらで保管すべきですか？

縦置き。Overland-Tandberg はメディアを垂直に保管するよう述べており、Dell はテープをケースに入れて縦に置き、決して積み重ねないよう述べています。

使用前にテープをどのくらいなじませるべきですか？

ドライブのある部屋で24時間。はるかに寒い、または湿度の高い場所から持ってきた場合はそれ以上置き、ドライブ内で結露が起きないようにします。

LTOテープを普通の耐火金庫に保管できますか？

紙専用の金庫では足りません。内部がテープの耐えられる温度よりはるかに高くなるためです。磁気メディア向けの定格の金庫かキャビネット（米国では UL 72 Class 150）を使うか、二つ目のコピーをオフサイトに置いてください。

テープをオフサイトに保管するには？

オンサイトと同じ条件の空調された場所で、クッション入りのケースで運び、暗号化し、どのカートリッジがどこにあるか常に分かるよう記録します。
