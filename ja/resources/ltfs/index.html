LTFSガイド

LTFS：リニアテープファイルシステム

LTFS（Linear Tape File System）はLTO-5以降のテープをディスクのようにマウントできるようにするため、通常のファイルマネージャーでファイルをコピーでき、あらゆるLTFSシステムでテープを読み取れます。IBM、HPE、Quantumから無料ツールが提供されており、オープンソース版も存在します。

概要

LTFSの機能

LTFS（Linear Tape File System）は、LTO-5以降のLTOカートリッジを二つのパーティションにフォーマットします。ファイルインデックスを保持する小さなパーティションと、ファイル本体を保持する大きなパーティションです。テープをマウントするとドライブまたはフォルダーとして認識され、通常のファイルマネージャーやコマンドラインでファイルを読み書きでき、書き込んだソフトウェアがなくても他のあらゆるLTFS環境で読み取ることができます。

自己記述型の形式であることから、LTFSは映画、テレビ、ポストプロダクションをはじめとする企業間でのテープ受け渡しの標準となっています。

使用方法

テープのフォーマットとマウント

Linuxのオープンソースツールを使用する場合、未フォーマットのカートリッジをmkltfsでフォーマットし、ltfsでマウント（両方ともドライブのデバイスファイルを指定）した後、通常通りマウントポイントにファイルをコピーします。取り出し前には必ずアンマウントしてください。LTFSはアンマウント時に最終インデックスを書き込むため、アンマウントせず取り出したテープでは直前のインデックスまでのファイルしか表示されない場合があります。

GUIツールでは、フォーマットボタンとドライブレターまたはボリューム指定によって同様の処理を行います。

制限事項

LTFSが適していない用途

  • 小さなファイル群。ファイルごとにインデックス領域とテープのシーク移動が発生します。数千個の小さなファイルはあらかじめ一つのアーカイブにまとめてください。
  • 削除。ファイルを削除しても空き容量は増えません。空き容量を回復するにはカートリッジ全体を再フォーマットする必要があります。
  • ランダムアクセス。テープの中間にあるファイルを開くにはそこまで巻き戻す必要があり、一〜二分かかることがあります。
  • バックアップ。LTFSはファイルシステムであり、バックアップソフトウェアではありません。単体でスケジュール、世代管理、検証を行うことはできません。

互換性

LTFSのバージョンとドライブ

LTFSはLTO-5以降のすべての世代で動作します。新しいLTFSバージョンは古いバージョンで書き込まれたテープを読み取れますが、古いツールは新しいインデックスバージョンでフォーマットされたテープを拒否することがあるため、テープをやり取りする際は同一または新しいバージョンを使用してください。ドライブがカートリッジ世代を読み取れる必要もあります。互換性についてはLTO容量表をご覧ください。

LTFSとは？

Linear Tape File System：LTO-5以降のテープをディスクのようにマウントし、通常通りファイルをコピーできるようにする形式で、インデックスはテープ自体に保存されます。

LTFSは無料ですか？

はい。IBM、HPE、Quantumが自社ドライブ向けに無料のLTFSソフトウェアを提供しており、GitHub上にはオープンソースの参照実装があります。

LTFSはMacやWindowsでも動作しますか？

はい。IBMとHPEがWindowsおよびmacOS向けにLTFSを提供しており、Thunderboltデスクトップドライブには通常付属しています。

LTFSテープ上のファイルを削除できますか？

インデックスから削除することはできますが、カートリッジ全体を再フォーマットするまでその領域は再利用されません。

LTFSはバックアップですか？

いいえ。これはファイルシステムです。スケジュール設定、世代管理、検証にはバックアップまたはアーカイブ用ソフトウェアを使用するか、ご自身でチェックサムと二次コピーを追加してください。
