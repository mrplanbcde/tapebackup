Leitfaden LTFS

LTFS: das Linear Tape File System

LTFS (Linear Tape File System) lässt ein Band ab LTO-5 wie eine Festplatte einbinden, Sie kopieren Dateien also mit dem normalen Dateimanager, und jedes LTFS-System kann das Band lesen; kostenlose Tools gibt es von IBM, HPE und Quantum sowie als Open Source.

Was es ist

Was LTFS macht

LTFS (Linear Tape File System) teilt eine LTO-Kassette ab LTO-5 in zwei Partitionen: eine kleine mit dem Dateiindex und eine große mit den Dateien. Binden Sie das Band ein, erscheint es als Laufwerk oder Ordner; Sie kopieren Dateien mit dem normalen Dateimanager oder der Kommandozeile, und jedes andere LTFS-System kann es ohne die Software lesen, die es geschrieben hat.

Dieses selbstbeschreibende Format ist der Grund, warum LTFS der Standard für den Austausch von Bändern zwischen Unternehmen ist, besonders in Film, Fernsehen und Postproduktion.

So nutzen Sie es

Ein Band formatieren und einbinden

Mit den Open-Source-Tools unter Linux formatieren Sie eine leere Kassette mit mkltfs und binden sie mit ltfs ein, beide auf das Gerät des Laufwerks gerichtet, und kopieren dann wie gewohnt Dateien in den Einhängepunkt. Hängen Sie das Band vor dem Auswerfen aus: LTFS schreibt den endgültigen Index beim Aushängen, und ein Band, das ohne diesen Schritt entnommen wird, zeigt eventuell nur die Dateien bis zum letzten Index.

Die grafischen Tools machen dasselbe mit einer Formatieren-Schaltfläche und einem Laufwerksbuchstaben oder Volume.

Grenzen

Wofür LTFS nicht taugt

  • Kleine Dateien. Jede Datei kostet Indexplatz und Bandbewegung; packen Sie Tausende kleine Dateien vorher in ein Archiv.
  • Löschen. Gelöschte Dateien geben keinen Platz frei. Platz gewinnen Sie erst zurück, wenn Sie die ganze Kassette neu formatieren.
  • Wahlfreier Zugriff. Eine Datei in der Mitte des Bands zu öffnen bedeutet, dorthin zu spulen, was ein bis zwei Minuten dauern kann.
  • Backup. LTFS ist ein Dateisystem, keine Backup-Software: Es plant, versioniert und verifiziert nichts von selbst.

Kompatibilität

LTFS-Versionen und Laufwerke

LTFS funktioniert ab LTO-5 mit jeder späteren Generation. Neuere LTFS-Versionen lesen Bänder älterer Versionen, aber ein altes Tool kann ein Band mit neuerer Indexversion ablehnen; nutzen Sie beim Austausch also dieselbe oder eine neuere Version. Das Laufwerk muss die Kassettengeneration trotzdem lesen können; zur Kompatibilität siehe die LTO-Kapazitätstabelle.

Was ist LTFS?

Linear Tape File System: ein Format, mit dem sich ein Band ab LTO-5 wie eine Festplatte einbinden lässt, mit normal kopierbaren Dateien und einem Index auf dem Band selbst.

Ist LTFS kostenlos?

Ja. IBM, HPE und Quantum bieten kostenlose LTFS-Software für ihre Laufwerke an, und eine Open-Source-Referenzimplementierung liegt auf GitHub.

Funktioniert LTFS auf Mac und Windows?

Ja. IBM und HPE bieten LTFS für Windows und macOS an, und Thunderbolt-Desktop-Laufwerke werden meist damit ausgeliefert.

Kann ich Dateien auf einem LTFS-Band löschen?

Sie können sie aus dem Index löschen, aber der Platz wird erst wiederverwendet, wenn Sie die ganze Kassette neu formatieren.

Ist LTFS ein Backup?

Nein. Es ist ein Dateisystem. Nutzen Sie Backup- oder Archivsoftware für Zeitpläne, Versionen und Verifizierung, oder ergänzen Sie selbst Prüfsummen und eine zweite Kopie.
