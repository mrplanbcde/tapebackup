Engere Auswahl

Software, die der Finder empfehlen kann

  • Catalogic DPX: auf Band ausgerichtetes Enterprise-Backup mit breiter Unterstützung für Laufwerke, Bandbibliotheken und NDMP.
  • Veeam Backup & Replication: die übliche Wahl für virtualisierte Umgebungen, mit Band-Jobs als sekundärem Ziel.
  • Commvault: große, funktionsreiche Plattform mit tiefer Cloud-Integration.
  • Nakivo: günstigere Option für kleinere Umgebungen, die grundlegende Tape-Unterstützung brauchen.
  • Veeam for Microsoft 365 und CloudCasa: Backup für SaaS und Kubernetes.

Welche Backup-Software eignet sich am besten für Bandbibliotheken?

Catalogic DPX unterstützt die meisten Laufwerke und Bandbibliotheken und beherrscht NDMP, was für NAS-Backups wichtig ist. Veeam und Commvault unterstützen Band gut als Zweitkopie in größeren virtuellen Umgebungen.

Kann ich Microsoft 365 auf Band sichern?

Nicht direkt. Sichern Sie die SaaS-Daten mit einem Tool wie Veeam for Microsoft 365 und kopieren Sie dessen Repository auf Band, wenn Sie eine Offline-Kopie oder eine Kopie mit langer Aufbewahrung brauchen.
