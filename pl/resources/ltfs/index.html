Poradnik LTFS

LTFS: Linear Tape File System

LTFS (Linear Tape File System) pozwala zamontować taśmę LTO-5 lub nowszą jak dysk, więc pliki kopiuje się zwykłym menedżerem plików, a taśmę odczyta każdy system z LTFS; bezpłatne narzędzia udostępniają IBM, HPE i Quantum, są też wersje open source.

Czym jest

Co robi LTFS

LTFS (Linear Tape File System) dzieli kasetę LTO, począwszy od LTO-5, na dwie partycje: małą z indeksem plików i dużą z samymi plikami. Po zamontowaniu taśma pojawia się jako dysk lub folder; pliki kopiuje się zwykłym menedżerem plików albo z wiersza poleceń, a każdy inny system z LTFS odczyta ją bez programu, który ją zapisał.

Ten samoopisujący się format sprawia, że LTFS jest standardem wymiany taśm między firmami, zwłaszcza w filmie, telewizji i postprodukcji.

Jak go używać

Formatowanie i montowanie taśmy

Z narzędziami open source w Linuksie pustą kasetę formatuje się poleceniem mkltfs i montuje poleceniem ltfs, wskazując w obu przypadkach urządzenie napędu, a potem kopiuje pliki do punktu montowania jak zwykle. Przed wysunięciem taśmę trzeba odmontować: LTFS zapisuje końcowy indeks przy odmontowaniu, a taśma wyjęta bez tego kroku może pokazywać tylko pliki do ostatniego indeksu.

Narzędzia graficzne robią to samo za pomocą przycisku formatowania i litery dysku lub woluminu.

Ograniczenia

W czym LTFS się nie sprawdza

  • Małe pliki. Każdy plik zajmuje miejsce w indeksie i wymaga ruchu taśmy; tysiące małych plików warto najpierw spakować do archiwum.
  • Usuwanie. Usunięte pliki nie zwalniają miejsca. Przestrzeń wraca dopiero po ponownym sformatowaniu całej kasety.
  • Dostęp swobodny. Otwarcie pliku ze środka taśmy wymaga jej przewinięcia, co może potrwać minutę lub dwie.
  • Kopia zapasowa. LTFS to system plików, a nie program do kopii zapasowych: sam niczego nie planuje, nie wersjonuje ani nie weryfikuje.

Zgodność

Wersje LTFS i napędy

LTFS działa z LTO-5 i każdą późniejszą generacją. Nowsze wersje LTFS odczytują taśmy zapisane przez starsze, ale stare narzędzie może odrzucić taśmę sformatowaną z nowszą wersją indeksu, dlatego przy wymianie taśm warto używać tej samej lub nowszej wersji. Napęd nadal musi obsługiwać generację kasety; zgodność opisuje tabela pojemności LTO.

Zobacz historię cen

Czym jest LTFS?

Linear Tape File System: format, który pozwala zamontować taśmę LTO-5 lub nowszą jak dysk, z plikami kopiowanymi w zwykły sposób i indeksem zapisanym na samej taśmie.

Czy LTFS jest bezpłatny?

Tak. IBM, HPE i Quantum udostępniają bezpłatne oprogramowanie LTFS dla swoich napędów, a referencyjna implementacja open source jest dostępna w serwisie GitHub.

Czy LTFS działa na Macu i w Windows?

Tak. IBM i HPE udostępniają LTFS dla Windows i macOS, a biurkowe napędy Thunderbolt zwykle mają je w zestawie.

Czy można usuwać pliki z taśmy LTFS?

Można je usunąć z indeksu, ale miejsce nie zostanie ponownie wykorzystane, dopóki cała kaseta nie zostanie sformatowana od nowa.

Czy LTFS to kopia zapasowa?

Nie. To system plików. Do harmonogramów, wersji i weryfikacji służy program do kopii zapasowych lub archiwizacji; można też samodzielnie dodać sumy kontrolne i drugą kopię.
