Guida a LTFS

LTFS: il Linear Tape File System

LTFS (Linear Tape File System) permette di montare un nastro LTO-5 o successivo come un disco, quindi si copiano i file con il normale gestore file e qualsiasi sistema LTFS può leggere il nastro; esistono strumenti gratuiti di IBM, HPE e Quantum e open source.

Che cos'è

Cosa fa LTFS

LTFS (Linear Tape File System) suddivide una cartuccia LTO, da LTO-5 in poi, in due partizioni: una piccola con l'indice dei file e una grande con i file. Montando il nastro, appare come un'unità o una cartella; si copiano i file con il normale gestore file o da riga di comando, e qualsiasi altro sistema LTFS può leggerlo senza il software che l'ha scritto.

Questo formato autodescrittivo è il motivo per cui LTFS è lo standard per scambiare nastri tra aziende, soprattutto nel cinema, nella TV e nella post-produzione.

Come si usa

Formattare e montare un nastro

Con gli strumenti open source su Linux si formatta una cartuccia vuota con mkltfs e la si monta con ltfs, indicando in entrambi i casi il dispositivo dell'unità, poi si copiano i file nel punto di montaggio come di consueto. Smontate prima di espellere: LTFS scrive l'indice finale allo smontaggio, e un nastro estratto senza questo passaggio potrebbe mostrare solo i file fino all'ultimo indice.

Gli strumenti grafici fanno lo stesso con un pulsante di formattazione e una lettera di unità o un volume.

Limiti

Dove LTFS non è adatto

  • File piccoli. Ogni file costa spazio nell'indice e movimento del nastro; conviene raccogliere prima migliaia di file piccoli in un archivio.
  • Eliminazione. I file eliminati non liberano spazio. Lo spazio si recupera solo riformattando l'intera cartuccia.
  • Accesso casuale. Aprire un file a metà nastro significa avvolgere il nastro fino a lì, il che può richiedere un paio di minuti.
  • Backup. LTFS è un file system, non un software di backup: non pianifica, non gestisce versioni e non verifica nulla da solo.

Compatibilità

Versioni di LTFS e unità

LTFS funziona con LTO-5 e con tutte le generazioni successive. Le versioni più recenti di LTFS leggono i nastri scritti da quelle precedenti, ma uno strumento vecchio può rifiutare un nastro formattato con una versione dell'indice più recente; per scambiare nastri usate quindi la stessa versione o una più recente. L'unità deve comunque leggere la generazione della cartuccia; per la compatibilità vedi la tabella delle capacità LTO.

Che cos'è LTFS?

Linear Tape File System: un formato che permette di montare un nastro LTO-5 o successivo come un disco, con file copiati normalmente e un indice registrato sul nastro stesso.

LTFS è gratuito?

Sì. IBM, HPE e Quantum offrono software LTFS gratuito per le loro unità, e un'implementazione di riferimento open source è disponibile su GitHub.

LTFS funziona su Mac e Windows?

Sì. IBM e HPE offrono LTFS per Windows e macOS, e le unità desktop Thunderbolt di solito lo includono.

Si possono eliminare file su un nastro LTFS?

Si possono eliminare dall'indice, ma lo spazio non viene riutilizzato finché non si riformatta l'intera cartuccia.

LTFS è un backup?

No. È un file system. Per pianificazione, versioni e verifica serve un software di backup o di archiviazione, oppure si aggiungono in proprio checksum e una seconda copia.
