Guía de consumibles

Limpieza, etiquetas y manipulación de cintas LTO

Un cartucho de limpieza LTO universal funciona en todas las generaciones y dura hasta 50 limpiezas, pero limpie solo cuando la unidad lo pida; las etiquetas de código de barras de las bibliotecas terminan en un código de soporte como L9 para datos LTO-9 o LZ para WORM LTO-9.

Limpieza

Cartuchos de limpieza LTO

Un cartucho de limpieza LTO universal funciona en unidades de todas las generaciones. Está garantizado para un máximo de 50 limpiezas, menos en algunas unidades, y la unidad lo rechaza cuando se agota.

Limpie solo cuando la unidad lo pida. Las unidades LTO avisan cuando necesitan limpieza y las bibliotecas pueden limpiar automáticamente; limpiar con un calendario fijo solo desgasta el cabezal. Si una unidad pide limpieza muy a menudo, sospeche de un cartucho defectuoso o de un cabezal que falla.

Etiquetas

Etiquetas de código de barras

Las bibliotecas y autocargadores identifican los cartuchos por código de barras. La etiqueta LTO estándar tiene seis caracteres a su elección y luego un código de soporte de dos caracteres: por ejemplo, 000001L9 es un cartucho de datos LTO-9 y 000001L8 uno LTO-8. Los cartuchos WORM usan códigos propios (LZ para WORM LTO-9, LY para WORM LTO-8), y los cartuchos de limpieza empiezan por CLN.

Compre etiquetas impresas para su generación, mantenga los números únicos en toda la biblioteca y no ponga nunca una etiqueta sobre el interruptor de protección contra escritura ni sobre los bordes del cartucho.

Estuches y transporte

Estuches para almacenar y para copias externas

Guarde cada cartucho en su estuche en una estantería y use maletas acolchadas para 5, 10 o 20 cartuchos cuando lleve cintas fuera de las instalaciones. Evite los cartuchos sueltos en una caja: las caídas y el polvo son las causas más habituales de daños por manipulación.

Eliminación

Destruir cintas antiguas

Borrar o sobrescribir una cinta lleva tanto tiempo como llenarla. Para cintas con datos confidenciales, use una trituradora de cintas o un servicio de destrucción que emita un certificado. La desmagnetización requiere un desmagnetizador apto para soportes de ferrita de bario de alta coercitividad y además borra las pistas servo, así que el cartucho no se puede reutilizar después.

¿Cuántas veces se puede usar un cartucho de limpieza LTO?

Hasta 50 veces, menos en algunas unidades. El cartucho registra sus usos y la unidad lo rechaza cuando se agota.

¿Con qué frecuencia debo limpiar una unidad LTO?

Solo cuando la unidad o la biblioteca lo pidan. La limpieza programada desgasta el cabezal sin ningún beneficio.

¿Qué significa L9 en una etiqueta LTO?

Es el código de soporte de un cartucho de datos LTO-9. L8 es LTO-8, L7 es LTO-7, y los cartuchos WORM usan códigos propios, como LZ para WORM LTO-9.

¿Cómo destruyo cintas LTO de forma segura?

Tritúrelas o use un servicio de destrucción con certificado. La desmagnetización solo funciona con un desmagnetizador apto para el soporte, y el cartucho no se puede reutilizar después.
