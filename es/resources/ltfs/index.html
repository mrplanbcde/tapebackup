Guía de LTFS

LTFS: el Linear Tape File System

LTFS (Linear Tape File System) permite montar una cinta LTO-5 o posterior como un disco, de modo que copia archivos con el explorador habitual y cualquier sistema LTFS puede leer la cinta; hay herramientas gratuitas de IBM, HPE y Quantum y de código abierto.

Qué es

Qué hace LTFS

LTFS (Linear Tape File System) divide un cartucho LTO, desde LTO-5, en dos particiones: una pequeña que guarda el índice de archivos y otra grande que guarda los archivos. Al montar la cinta aparece como una unidad o una carpeta; copia archivos con el explorador habitual o la línea de comandos, y cualquier otro sistema LTFS puede leerla sin el software que la escribió.

Ese formato autodescriptivo es la razón por la que LTFS es el estándar para intercambiar cintas entre empresas, sobre todo en cine, televisión y posproducción.

Cómo usarlo

Formatear y montar una cinta

Con las herramientas de código abierto en Linux, formatee un cartucho virgen con mkltfs y móntelo con ltfs, indicando en ambos el dispositivo de la unidad, y luego copie archivos al punto de montaje como de costumbre. Desmonte antes de expulsar: LTFS escribe el índice final al desmontar, y una cinta extraída sin ese paso puede mostrar solo los archivos hasta el último índice.

Las herramientas gráficas hacen lo mismo con un botón de formateo y una letra de unidad o un volumen.

Límites

En qué no es bueno LTFS

  • Archivos pequeños. Cada archivo consume espacio de índice y movimiento de cinta; agrupe antes miles de archivos pequeños en un archivo comprimido.
  • Borrado. Los archivos borrados no liberan espacio. El espacio solo se recupera al volver a formatear todo el cartucho.
  • Acceso aleatorio. Abrir un archivo en mitad de una cinta obliga a bobinarla hasta él, lo que puede llevar uno o dos minutos.
  • Copia de seguridad. LTFS es un sistema de archivos, no un software de copia de seguridad: no programa, no versiona ni verifica nada por sí mismo.

Compatibilidad

Versiones de LTFS y unidades

LTFS funciona con LTO-5 y con todas las generaciones posteriores. Las versiones nuevas de LTFS leen cintas escritas por las antiguas, pero una herramienta antigua puede rechazar una cinta formateada con una versión de índice más reciente, así que use la misma versión o una más nueva al intercambiar cintas. La unidad debe poder leer la generación del cartucho; consulte la tabla de capacidades LTO para la compatibilidad.

¿Qué es LTFS?

Linear Tape File System: un formato que permite montar una cinta LTO-5 o posterior como un disco, con archivos que se copian con normalidad y un índice guardado en la propia cinta.

¿LTFS es gratuito?

Sí. IBM, HPE y Quantum ofrecen software LTFS gratuito para sus unidades, y hay una implementación de referencia de código abierto en GitHub.

¿Funciona LTFS en Mac y Windows?

Sí. IBM y HPE ofrecen LTFS para Windows y macOS, y las unidades de sobremesa Thunderbolt suelen incluirlo.

¿Se pueden borrar archivos en una cinta LTFS?

Puede borrarlos del índice, pero el espacio no se reutiliza hasta que vuelva a formatear todo el cartucho.

¿Es LTFS una copia de seguridad?

No. Es un sistema de archivos. Use software de copia de seguridad o de archivo para la programación, las versiones y la verificación, o añada usted mismo sumas de verificación y una segunda copia.
