Guía de bibliotecas

Bibliotecas de cintas y autocargadores LTO

Un autocargador LTO tiene una unidad y unos 8 a 16 cartuchos, mientras que una biblioteca tiene una o más unidades y 25 o más ranuras por módulo; dé el paso cuando una copia de seguridad ocupe varios cartuchos o no haya nadie para cambiar las cintas.

Cuándo la necesita

Unidad, autocargador o biblioteca

Una sola unidad basta mientras cada copia de seguridad quepa en un cartucho y alguien cambie las cintas. En cuanto un trabajo ocupa varios cartuchos, se ejecuta de noche o se llevan cintas fuera de las instalaciones cada semana, un cambiador automático se amortiza en tiempo de personal y copias no perdidas.

  • Autocargador: una unidad y un cargador de unas 8 a 16 ranuras en 1U o 2U. Adecuado para una oficina pequeña o un solo servidor.
  • Biblioteca pequeña: una o más unidades y de 25 a 50 ranuras por módulo, ampliable apilando módulos. Adecuada para un entorno mediano o varios flujos de copia de seguridad.
  • Biblioteca empresarial: de cientos a miles de ranuras y decenas de unidades, repartidas entre aplicaciones.

Qué comprobar

Lista de comprobación de compra

  • Generación y número de unidades. Con dos unidades puede copiar de cinta a cinta y hacer copias y restauraciones a la vez.
  • Interfaz. SAS para un solo host, Fibre Channel para compartir la biblioteca en una SAN.
  • Lector de códigos de barras y etiquetas. Las bibliotecas identifican los cartuchos por código de barras, así que cada cinta necesita una etiqueta con el formato correcto. Consulte etiquetas y cartuchos de limpieza.
  • Ranuras de correo. Las ranuras de E/S permiten sacar cartuchos para llevarlos fuera de las instalaciones sin abrir el cargador.
  • Compatibilidad de software. El modelo de biblioteca, no solo la unidad, debe figurar en la lista de compatibilidad de su software de copia de seguridad.
  • Particionado y gestión de claves de cifrado si la comparten varias aplicaciones o equipos.

Capacidad

Cuánto almacena una biblioteca

Multiplique las ranuras por la capacidad nativa: una biblioteca de 40 ranuras almacena 720 TB en LTO-9 o 1,2 PB con cartuchos LTO-10 de 30 TB, antes de compresión. Reserve algunas ranuras para cartuchos de limpieza y para cintas pendientes de salir. Los precios de los cartuchos están en el seguimiento de precios LTO.

¿Qué diferencia hay entre un autocargador y una biblioteca de cintas?

Un autocargador tiene una unidad y un único cargador de unas 8 a 16 ranuras. Una biblioteca tiene una o más unidades, más ranuras y normalmente se puede ampliar con módulos adicionales.

¿Cuántas cintas caben en una biblioteca LTO pequeña?

Los módulos base suelen alojar de 25 a 50 cartuchos, es decir, de 450 a 900 TB en LTO-9, y la mayoría se pueden ampliar apilando módulos.

¿Las bibliotecas de cintas necesitan etiquetas de código de barras?

Sí. La biblioteca identifica cada cartucho por su etiqueta de código de barras, así que cada cartucho de datos y de limpieza necesita una con el formato que espera la biblioteca.

¿Se pueden mezclar generaciones LTO en una biblioteca?

Normalmente sí, con unidades de cada generación, siempre que la biblioteca y su software de copia de seguridad admitan ambas. Cada unidad sigue leyendo solo sus generaciones compatibles.
