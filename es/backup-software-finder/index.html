Preselección

Software que puede recomendar este buscador

  • Catalogic DPX: copia de seguridad empresarial centrada en cinta, con amplia compatibilidad con unidades, bibliotecas y NDMP.
  • Veeam Backup & Replication: la opción habitual en entornos virtualizados, con tareas de cinta como destino secundario.
  • Commvault: plataforma grande y muy completa, con una profunda integración con la nube.
  • Nakivo: opción más económica para entornos pequeños que necesitan compatibilidad básica con cinta.
  • Veeam for Microsoft 365 y CloudCasa: copias de seguridad de SaaS y Kubernetes.

¿Qué software de copia de seguridad es el mejor para bibliotecas de cintas?

Catalogic DPX tiene la compatibilidad más amplia con unidades y bibliotecas y gestiona NDMP, algo importante para las copias de seguridad de NAS. Veeam y Commvault admiten bien la cinta como copia secundaria en entornos virtuales más grandes.

¿Puedo hacer copias de seguridad de Microsoft 365 en cinta?

No directamente. Haga una copia de seguridad de los datos SaaS con una herramienta como Veeam for Microsoft 365 y luego copie su repositorio a cinta si necesita una copia sin conexión o de conservación prolongada.
