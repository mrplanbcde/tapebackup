对比

LTO 磁带与对象存储

对象存储毫秒级响应但每月收费；LTO 磁带在磁带库中几分钟响应，但LTO-9上 100 TB 的两份副本一次性只需 $ 8,808 至 $ 14,839，离线磁带盒勒索软件够不着，所以大多数大型归档两者并用。

简短回答

选 LTO 磁带还是对象存储？

对象存储（Amazon S3 以及使用相同 API 的服务，在云端或在您自己的服务器上）通过 API 让每个对象保持在线，因此任何应用都能在毫秒内读取。LTO 磁带把数据放在大多时候离线的磁带盒上，所以读取在磁带库中要几分钟，但每 TB 保存多年的成本只有标准对象存储的一小部分，放在架上的磁带盒也避开了网络攻击。

大多数数据量很大的机构两者并用：经常读取的数据放对象存储，归档和离线副本放磁带。现在一些产品还通过 S3 接口提供磁带，下文会讲到。

两者并用

磁带之上的 S3

S3-to-tape网关通过 S3 或 S3 Glacier API 接收对象，并把它们写到磁带库中的 LTO 磁带盒上，通常还把较新的对象保留在硬盘上。这样，已经支持 S3 的应用无需专用磁带软件就能归档到磁带。我们 Ledger 中评分的例子包括 Spectra BlackPearl、Grau Data XtreemStore、PoINT Archival Gateway、带 S3 网关的 Versity ScoutAM，以及 QStar。要按您的数据量和团队情况比较它们，请试试磁带归档顾问。

如何抉择

何时选哪个

  • 选择对象存储：应用要频繁读取数据，需要从任何地方访问，或者数据集很小（低于约 15 TB 时，买磁带机比云存储用多年还贵）。
  • 选择 LTO 磁带：归档以数十 TB 或更多速度增长，数据必须保存多年，以及3-2-1方案中的离线副本。
  • 两者并用：归档既要让 S3 应用能访问，又要存得便宜时，可以在磁带库前面放一个S3-to-tape网关，或者把热数据放在对象存储，其余分层到磁带。

LTO 存储如何工作以及现在每 TB 成本多少，见 LTO 存储详解。

LTO 磁带比对象存储便宜吗？

与 S3 Standard 或 Wasabi 这类标准对象存储相比，是的，而且便宜得多：LTO-9上 100 TB 的两份副本，含磁带机一次性只需 $ 8,808 至 $ 14,839。与云归档层级相比则取决于容量和恢复次数：100 TB 放在 Glacier Deep Archive 五年的存储费为 $ 5,532，比磁带便宜，但全部读回一次还要增加约 $ 8,615。从约 500 TB 起，或者经常恢复时，磁带成本更低。

LTO 磁带比对象存储快吗？

流式写入大文件时，LTO-9磁带机原生速度最高可写 400 MB/s。读取随机文件的首字节，对象存储快得多：毫秒级，而磁带库中的磁带约需一两分钟。

S3 能和磁带一起用吗？

可以。Spectra BlackPearl、Grau Data XtreemStore 和 PoINT Archival Gateway 等S3-to-tape网关接收 S3 或 S3 Glacier 请求，并把对象存到 LTO 磁带盒上。

对象存储能防勒索软件吗？

可以，前提是启用 Object Lock 或不可变设置，并严格控制访问密钥。磁带还多一层物理隔离：放在架上的磁带盒根本无法通过网络访问。

应该用对象存储取代磁带吗？

通常不会完全取代。很多站点把常用数据放在对象存储，把归档和离线副本放在磁带，因为数据保存越久，磁带每 TB 成本越低。
