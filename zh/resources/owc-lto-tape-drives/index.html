磁带机指南

OWC Mercury Pro 与 Archive Pro LTO 磁带机

OWC 现已把原来的 Mercury Pro LTO Thunderbolt 磁带机改称 Archive Pro，在 OWC 美国商店提供LTO-7、LTO-8和LTO-9版本，内置 IBM 磁带机，附带 Hedge Canister，价格从$ 5,999.99的 LTO-7 到$ 12,499.99的 LTO-9；Archive Pro Ethernet 通过 10 GbE 共享一台磁带机，OWC 目前还没有LTO-10磁带机。

产品系列

OWC 目前的 LTO 磁带机

OWC（Other World Computing）销售桌面外壳式 LTO 磁带机，主要面向 Mac 用户和视频团队。目前有两条产品线：

  • OWC Archive Pro：桌面式LTO-7、LTO-8或LTO-9磁带机，通过 Thunderbolt 连接，可选内置 4 或 8 TB SSD，用于暂存数据。
  • OWC Archive Pro Ethernet：思路相同的网络设备，通过10千兆以太网（iSCSI）共享磁带机，2025年四月发布。

Mercury Pro LTO 是这款 Thunderbolt 磁带机的早期名称。OWC 当前手册的标题是“Archive Pro LTO | Mercury Pro LTO”，并称 Mercury Pro 用户为旧版用户，所以人们搜索的 Mercury Pro LTO-9 和 LTO-7 型号，实际上现在以 Archive Pro 的名义销售。截至2026年十月17日，我们没有找到 OWC 的LTO-10产品。

无论外壳是什么，LTO 规则都一样：LTO-9磁带机可读写LTO-8和LTO-9磁带盒，更老的则不行。如果您的归档在LTO-6或LTO-7上，选购前请确认哪款型号还能读取。LTO-7如今已是三代之前的产品，所以LTO-7套件主要适合读取或扩充现有的LTO-7归档。

评测

评测者怎么说

  • TechRadar Pro在2022年评测了 Mercury Pro LTO-9：磁带的成本优势明显，但管理分散在许多 18 TB 磁带上的归档比想象的难，而且当时$ 6,299的价格不含 ArGest 许可。
  • 视频剪辑培训师 Larry Jordan 在2021年测试了一台 Mercury Pro LTO-8 借用机，尽管前期投入不低，仍推荐用于媒体归档。

截至2026年十月17日，我们没有找到当前 Archive Pro 或 Archive Pro Ethernet 的独立评测。我们自己也没有测试过这些磁带机。

适合谁

什么时候适合选 OWC 磁带机

适合：基于 Mac 的视频或摄影工作室，想要一台通过 Thunderbolt 插上即用、自带归档软件、无需在电脑内部安装任何东西的设备。Archive Pro Ethernet 适合想让多位剪辑师共用一台磁带机的小团队。

另寻他选：如果您已有带 SAS 接口的服务器，来自 HPE、IBM 或 Quantum 的裸外置 SAS 磁带机更便宜；如果需要LTO-10，OWC 目前还没有；如果需要容纳多盒磁带的磁带库，请看 LTO 磁带库。其他桌面 Thunderbolt 品牌见 LTO 磁带机选购指南，其他归档软件，包括 YoYotta 和 Archiware P5，见磁带归档顾问。

OWC Mercury Pro LTO 还在销售吗？

换了新名字。OWC 现在把 Thunderbolt LTO 磁带机作为 Archive Pro 销售，其手册同时涵盖 Archive Pro 和 Mercury Pro LTO。列出了LTO-7、LTO-8和LTO-9版本。

OWC Archive Pro 内置的是哪款磁带机？

IBM LTO Ultrium 磁带机；LTO-9型号使用 IBM Ultrium 9 机芯。最初的2020 Mercury Pro LTO 使用 IBM LTO-8 磁带机。

OWC Archive Pro LTO-9 多少钱？

17年十月2026日在 OWC 美国商店，含 Hedge Canister 的$ 12,499.99套件标价如此，带 8 TB 内置 SSD 的最高为 $ 14,899.99。Archive Pro Ethernet LTO-9标价 $ 14,999.99。

OWC Archive Pro 能用于 Windows 吗？

可以。OWC 列出了 Windows 10 和 11、Windows Server 2022，以及 macOS 和 Linux。它通过 Thunderbolt 连接，所以电脑需要有 Thunderbolt 接口。

OWC 有LTO-10磁带机吗？

截至2026年十月17日没有。Archive Pro 和 Archive Pro Ethernet 的磁带机有LTO-7、LTO-8和LTO-9。

Archive Pro 与 Archive Pro Ethernet 有什么区别？

Archive Pro 通过 Thunderbolt 连接一台电脑。Archive Pro Ethernet 放在网络上，通过10千兆 iSCSI 与多台工作站共享磁带机。
