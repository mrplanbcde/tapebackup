选择磁带备份软件前需考查的要素

无论您最终入选哪款产品，请对照您自有的驱动器或磁带库逐一核实这六个要点。磁带库指南与备份计算器可在硬件规划方面提供参考。

考查重要性所在
LTO世代与接口请确认该软件支持您的LTO世代以及驱动器或磁带库连接方式（SAS或Fibre Channel）。不兼容的驱动器可能会导致采购无法落地。
LTFS支持写入LTFS的软件可使磁带在日后无需依赖该软件即可读取，这在更换厂商或数年后恢复数据时极具价值。
流式读写速度LTO驱动器需要稳定的数据流。请检查备份软件如何对作业进行暂存或复用，以避免驱动器频繁停顿与重启。
加密与 WORMLTO-4及更新的驱动器采用AES-256进行硬件加密，WORM磁带盒可防止数据被覆盖。请了解该软件如何管理密钥和WORM介质。
目录与恢复跨多盒磁带搜索并快速恢复单个文件取决于目录功能。在决定采用之前，请务必测试一次完整恢复。
异地存放与保留周期请关注针对出库磁带的介质跟踪功能、过期与回收规则，以及每盘磁带存放位置的记录。

备份到LTO磁带的最佳软件是什么？

这取决于您的IT环境。对于主要为虚拟化且使用磁带作为第二副本的环境，Veeam是常见选择；Commvault适合大型混合物理、虚拟和云架构；Nakivo则是适合小型环境的低成本选项。上方的推荐工具通过四个问题即可缩小选择范围。

向LTO磁带写入数据是否需要备份软件？

对于简单的归档并非必需。借助驱动器厂商提供的免费工具，LTFS 可让您像使用驱动器一样将文件复制到 LTO-5 或更新的磁带盒中。而备份软件则补充了 LTFS 所欠缺的能力：调度、跨多盒磁带的可检索目录、校验、保留规则以及磁带库控制。

Veeam是否支持备份到磁带？

是的。Veeam Backup & Replication 可以将备份写入磁带库和独立磁带机，通常作为保存在磁盘上的备份的第二副本或长期副本。购买前请检查您的驱动器或磁带库及其世代是否在供应商的支持列表中。

我能将 Microsoft 365 备份到磁带吗？

无法直接实现。可以使用 Veeam for Microsoft 365 等工具备份 SaaS 数据，如果需要离线或长期保留副本，再将其存储库复制到磁带。

选择磁带备份软件前我应该核实哪些事项？

检查它是否支持您的 LTO 世代和驱动器或磁带库接口（SAS 或 Fibre Channel），是否可以写入 LTFS，如何处理加密、WORM 和异地介质追踪，以及从目录中恢复的速度与可靠性。在决定采用之前测试一次完整恢复。

有免费的磁带备份软件吗？

是的。Bacula Community、Bareos 和 Amanda 是支持磁带机与磁带库的开源备份系统，对于简单任务，tar 搭配 LTFS 同样适用。它们不需要许可费用，但您需要自行构建和维护目录、调度排程与监控。
